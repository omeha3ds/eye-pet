# EYE•PET OS — Waveshare ESP32-S3-Touch-AMOLED-1.75C

Власна прошивка (Clean-Room C++) та веб-конфігуратор у стилі Google Pixel Material You для брелока на базі плати **Waveshare ESP32-S3-Touch-AMOLED-1.75C**.

## Веб-конфігуратор та Прошивка в 1 клік
Після завантаження цих файлів у репозиторій ваш сайт автоматично запрацює за адресою:
**https://omeha3ds.github.io/eye-pet/**

### Що входить у репозиторій:
- `firmware/` — вихідний код прошивки на C++ (PlatformIO / ESP32-S3) зі збереженням налаштувань у NVS-пам'ять, режимом енергозбереження 20 FPS, сенсорами та 17-годинним логером батареї.
- `web/` — готовий веб-конфігуратор із живим Web Serial підключенням по кабелю та кнопкою **ESP Web Tools** для прошивки плати прямо з браузера.
- `.github/workflows/deploy.yml` — автоматичний робот-збирач GitHub Actions, який сам компілює C++ код у `.bin` файли та публікує сайт на GitHub Pages.
